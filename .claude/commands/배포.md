# 배포

GitHub에 변경사항을 자동으로 커밋하고 푸시합니다.

## 실행 흐름

1. 현재 변경된 파일 확인 (git status)
2. 변경 내용 분석하여 커밋 메시지 자동 생성
3. 모든 파일 스테이징 (git add)
4. 생성된 메시지로 커밋 (git commit)
5. GitHub에 푸시 (git push)
6. "배포 완료" 메시지 출력

## 명령어 실행

변경된 파일들을 확인하고, 의미 있는 커밋 메시지를 자동으로 생성한 후 GitHub에 배포합니다.

먼저 git status로 변경된 파일을 확인하고, 그 내용을 기반으로 적절한 커밋 메시지를 생성합니다.

변경 내용이 있으면:
- 추가된 파일: "추가: 파일명" 형식
- 수정된 파일: "수정: 파일명" 형식  
- 삭제된 파일: "삭제: 파일명" 형식

git add . 로 모든 변경사항을 스테이징하고, 생성된 메시지로 커밋한 후 git push origin main으로 푸시합니다.

최종적으로 "✅ 배포 완료!" 메시지를 출력합니다.

변경사항이 없으면 "ℹ️ 변경사항이 없습니다. 배포를 건너뜁니다." 메시지를 출력합니다.
